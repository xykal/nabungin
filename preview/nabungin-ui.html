Yang beneran jalan di app

  • Room + Flow: 3 tabel (goals, deposits, auto_rules) dengan ON DELETE CASCADE
  • WorkManager: periodic auto-save tiap jam + pengingat harian pada jam pilihan user
  • Kunci aplikasi: PIN 6 digit (PBKDF2-HMAC-SHA256, 120k iterasi, salt 128-bit) + BiometricPrompt
  • Backup JSON lewat Storage Access Framework, tanpa server
  • Statistik: pace harian, ETA per tujuan, streak, grafik 30 hari (Canvas sendiri)
  • Unit test JVM untuk Money/Date/SavingsMath, ikut jalan di CI sebelum APK di-assemble

Build & distribusi

  • GitHub Actions: build.yml jalanin testDebugUnitTest, assembleDebug, assembleRelease
  • APK di-upload sebagai artifact + SHA256SUMS, tag v* otomatis bikin GitHub Release
  • Keystore diambil dari secrets.KEYSTORE_BASE64, tidak pernah ditulis ke repo
